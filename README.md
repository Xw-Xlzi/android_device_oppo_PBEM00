# Android Device Tree for OPPO R17 (PBEM00)

The OPPO R17 (codenamed _"PBEM00"_) is a smartphone from OPPO.
It was released in August 2018.

## Spec Sheet

| Feature                 | Specification                                                              |
| :---------------------- | :--------------------------------                                          |
| CPU                     | Octa-core (2x2 GHz Kryo 360 Gold & 6x1.7 GHz Kryo 360 Silver)              |
| Chipset                 | Qualcomm SDM670 Snapdragon 670 (10 nm)                                     |
| GPU                     | Qualcomm Adreno 615                                                        |
| Memory                  | 6 GB / 8 GB                                                                |
| Shipped Software        | Android 8.1, ColorOS 5.2.1                                                 |
| Storage                 | 128 GB                                                                     |
| Battery                 | 3500 mAh                                                                   |
| Dimensions              | 157.5 x 74.9 x 7.5 mm (6.20 x 2.95 x 0.30 in)                              |
| Display                 | 6.7 inches, 108.6 cm2 (~91.5% screen-to-body ratio)                        |
